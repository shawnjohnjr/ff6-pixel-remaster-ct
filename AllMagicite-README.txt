使用
1. 備份存檔，開啟 FF6、讀取存檔，停在一般地圖上並暫停操作。
2. Cheat Engine 連接 FINAL FANTASY VI.exe，開啟此 CT。
3. 勾選唯一項目一次，等待完成訊息，重新開啟魔石選單核對。
4. 確認後另存新欄位。取消勾選不會還原，完整還原請讀取原存檔。
檔案預設未啟用，開啟時不自動執行。仍需要 Mono collector。

檢查方式
核對執行檔版本、27 個內容 ID、已有清單及重複項目，使用遊戲 UserDataClient.AddOwnedMagicStone 新增未持有項目。
套用後核對全部 27 種、原有順序，並核對角色身分、職業、經驗值、等級、四項能力、HP/MP、魔石裝備、技能、指令、金錢與當前地圖不變。
若新增或核對失敗，會嘗試移除本次新增的魔石；還原失敗需讀取原存檔。
