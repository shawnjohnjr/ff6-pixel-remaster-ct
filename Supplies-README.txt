FF6 Pixel Remaster 補給 CT
適用 Steam build 20265119

同一份 CT 提供四個獨立勾選項目：特級乙太、終極萬靈藥、傳送石、魔石碎片。
勾選後會詢問要補至多少個，可輸入 1–99 的整數，預設 99。
這是補至指定總數，不是額外增加指定數量；原有數量較多時保留。

使用方式
1. 備份存檔，讀取遊戲，停在一般地圖上並暫停操作。
2. Cheat Engine 連接 FINAL FANTASY VI.exe，開啟 FF6_PR_Supplies_20265119.CT。
3. 勾選需要的道具，輸入補至數量，等候完成提示。
4. 重新開啟道具選單核對，確認後另存新欄位。
5. 下次補給先取消勾選再勾選，即可重新選數量。

四個項目預設全未勾選，開啟 CT 不會自動修改。取消數量輸入不會補給；若該項仍顯示勾選，先取消勾選再重新執行。取消勾選不會撤回已取得的道具。
