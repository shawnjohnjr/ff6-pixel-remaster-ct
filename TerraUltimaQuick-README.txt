使用
1. 備份存檔，讀取遊戲並停在一般地圖，暫停操作。
2. Cheat Engine 連接 FINAL FANTASY VI.exe，開啟此 CT。
3. 勾選單一項目一次，等待完成提示，重新開啟蒂娜的魔法清單核對。
4. 確認後另存新欄位。取消勾選不會忘記已學會的魔法；還原需讀取原存檔。
開啟檔案不會自動套用。需要 Cheat Engine Mono collector。
如果中途失敗，先前已成功學會的魔法不會自動撤回。
